# CFA Level I Study App

Single-page study app (flashcards, module quizzes, weighted mock exam, formula sheet), organized by the 2026 CFA Level I learning modules.

- Questions and flashcards are original, written from the curriculum module overviews; each is tagged with volume, learning module and page range.
- No CFA Institute practice problems or glossary text are included.
- Progress is saved in the browser (localStorage).

Open `index.html` via GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
